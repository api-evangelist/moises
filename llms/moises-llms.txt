# Moises / Music AI

> Moises is the creative suite for musicians from Music AI, Inc., serving 70M+ musicians with AI audio tools (stem separation, chord/key detection, AI-generated stems, voice synthesis). The same models power the Music AI developer platform — a B2B REST API that runs audio through composable Modules and Workflows as asynchronous Jobs. API-key authenticated; base URL https://api.music.ai/v1.

## APIs
- [Music AI API docs](https://music.ai/docs/): Developer documentation home.
- [API reference](https://music.ai/docs/api/reference/): Endpoints for upload, jobs, workflows, application.
- [Quick start](https://music.ai/docs/getting-started/quick-start/): Upload → create job → poll → results.
- [Authentication](https://music.ai/docs/api/authentication/): API key in the Authorization header.
